## 怎么推送到影视仓 / TVBox

1. 打开影视仓 / TVBox，按[接口配置图文教程](https://b.zhuiju.me/p/5)的相同路径进入「设置」→「配置地址」。
2. 打开该入口显示的二维码推送页或远程推送页，进入与配置地址相同的推送界面。
3. 在页面下方找到「直播源推送」，在「直播源名字」中填写便于辨认的名称，例如「VMA」或「饭太硬」。
4. 从上表复制对应的完整地址，粘贴到下方的「直播源地址」，点击下方的「推送」。
5. 回到影视仓 / TVBox 的直播页面，等待列表加载；如果没有立即出现，可尝试刷新或重新打开直播页面。

配置地址和直播源进入这个页面的路径相同，区别只在填写位置：配置地址填上方的「仓库/线路推送」，本文的直播源地址填下方的「直播源推送」。不同版本的推送页和播放器界面可能略有差异，以页面上的字段名称为准。

## 直播源和单个频道地址有什么区别

直播源通常是一个频道列表，导入后播放器会显示多个频道。单个直播流地址则只指向一个频道。常见的 M3U 列表会以 `#EXTM3U` 开头，用 `#EXTINF` 描述频道，下一行放对应的播放地址；可以参考 [iptv-org 的播放列表格式说明](https://github.com/iptv-org/iptv/blob/master/docs/playlists.md)。

地址末尾的 `.txt` 或 `/tv` 只是网址的一部分，不能单凭后缀判断内容格式。最终能否在影视仓 / TVBox 中播放，要看地址实际返回的内容，以及所用版本是否支持该格式。其他播放器也可能有不同的导入方式；例如 [Kodi 的 IPTV Simple Client](https://kodi.wiki/index.php?title=Add-on:IPTV_Simple_Client) 支持 M3U 播放列表。

## 常见问题

### 地址能打开，但播放器里没有频道？

先确认地址填在下方的「直播源地址」，并且已经点击该区域的「推送」。再查看打开地址后得到的是播放列表文本、下载文件，还是普通网页或错误提示。如果拿到的不是当前版本支持的列表格式，就可能无法显示频道；可以换一条直播源地址试试。

### 有频道列表，点开却一直缓冲？

列表可加载只说明播放器拿到了频道信息；每个频道的播放地址还需要单独连通。第三方直播流可能失效、限制地区或受到当前网络影响。先试同一列表里的其他频道，再尝试切换网络或直播源。

### 为什么 HTTP 地址在有些设备上无法导入？

有些应用或网络环境会限制明文 HTTP 请求。表中饭太硬和肥猫使用 `http://`，如果设备提示连接失败，可以先用同一网络的浏览器检查地址是否能打开，再排查播放器的网络访问设置。不要自行把 `http://` 改成 `https://`，除非来源明确提供了 HTTPS 地址。

### 直播源需要填到影视仓配置地址里吗？

不需要。影视仓配置接口和直播播放列表是两类入口。在截图所示的推送页面，本文地址应填入下方的「直播源地址」，再点击下方的「推送」。需要上方仓库/线路配置地址，可以看[影视仓配置地址整理](https://b.zhuiju.me/p/3)。
